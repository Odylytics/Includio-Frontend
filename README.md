# Includio Frontend

React + TypeScript + Vite prototype for **Includio — Inclusive Studio**.

## Stack

- React, TypeScript, Vite
- Tailwind CSS v4
- React Router, Zustand, TanStack Query
- lucide-react, Framer Motion (available; transitions kept restrained)

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

- No real backend, AI, recording, or calendar integration.
- Demo data mirrors Northwind Labs / Software Engineering Intern flows from `reference/Demo-1`.
- Brand assets live in `public/` and `reference/Brand System/`.
